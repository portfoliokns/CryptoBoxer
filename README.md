# CryptoBox

CryptoBoxは、画像、動画、PDF、音声、テキストなどの個人ファイルを暗号化し、macOS本体、外付けストレージやクラウドストレージなど、お好きな場所に安全にファイルを保存するためのmacOS向けセキュリティツールです。
Appleの `CryptoKit` を用いた強力な暗号化（AES-GCM）と、パスワードから暗号化キーを生成する堅牢な鍵ストレッチング機構を備えています。

> [!WARNING]
> **⚠️ セキュリティ上の条件**
> 本アプリをご利用の際は、macOSのディスク暗号化機能である **FileVault を必ず有効（ON）** にしてください。
> 閲覧時の一時的な復号やOSの仮想メモリ機構によるメモリ情報のスワップが発生した際に、ディスク全体が暗号化されていないと、一時的な平文データや鍵情報が物理ディスク上に残るリスクがあります。

---

## 💡 主な機能 (Features)

- **強力な暗号化 (AES-GCM)**: Appleの安全な暗号化ライブラリ `CryptoKit` を使用し、ファイルデータをAES-GCM形式で暗号化して保存します。
- **堅牢なキー生成 (Key Stretching)**: パスワードをそのまま使用するのではなく、SHA-256を用いた300万回のストレッチング処理を行うことで、ブルートフォース攻撃（総当たり攻撃）に対して非常に強い耐性を持つ暗号化キー（SymmetricKey）を生成します。
- **ファイルの匿名化機能**: 暗号化保存時にファイル名をUUIDに自動変換するオプションを搭載。ファイル名から中身を推測されるのを防ぎます。
- **元ファイルの自動削除**: ファイルの暗号化保存が成功した際、元のファイル（プレーンデータ）を自動的に削除してストレージをクリーンに保つことができます。
- **スムーズな一時プレビュー**: 暗号化されたファイル（鍵アイコン）をクリックすると、一時フォルダ（`tmp`）に復号されたファイルが生成され、Finderでその場所が開きます。
- **各種エクスポート機能**:
  - **一括書き出し (暗号化)**: 暗号化されたファイルのまま指定したフォルダへコピー（バックアップ）します。
  - **一括書き出し (復号化)**: 暗号化ファイルをパスワードを用いて復号した状態で指定したフォルダへ一括保存します。
- **データの完全消去**: アプリ内からワンクリックで、CryptoBoxに保存されているすべての暗号化データおよびプレビュー用一時フォルダの内容をクリーンアップできます。

---

## 📂 データの保存先 (Data Locations)

本アプリが使用するデータは、macOS標準のアプリケーションサポートフォルダ内に保存されます。

| フォルダ名 | パス | 用途 |
| :--- | :--- | :--- |
| **storage** | `~/Library/Application Support/CryptoBox/storage/` | 暗号化されたファイル（実データ）が格納される場所 |
| **tmp** | `~/Library/Application Support/CryptoBox/tmp/` | プレビュー閲覧時に一時的に復号されたファイルが置かれる場所 |

## 🚀 使い方 (Usage)

### 1. パスワード設定（初回または変更時）
1. メイン画面の **「パスワード設定」** をクリックします。
2. 暗号化および復号に使用するパスワードを入力します。
3. *誤入力を防止したい場合*は、「パスワード(再)を入力する」のトグルをONにし、確認用パスワードを入力します。
4. **「設定」** ボタンを押すと、入力したパスワードから300万回ストレッチングされたキーが生成され、メモリ上に保持されます。
   > [!NOTE]
   > パスワードの文字列自体はキーの生成直後にメモリから破棄され、アプリ起動中は生成された暗号化キー（`SymmetricKey`）のみがメモリ上で保持されます（アプリの終了によってメモリ上のキーは消去されるため、起動のたびにパスワードを入力してキーを再生成する必要があります）。

### 2. ファイルの暗号化アップロード
1. メイン画面の **「暗号化アップロード」** をクリックします。
2. 必要に応じて以下のオプションを設定します：
   - **ファイル名を匿名化する**: ONにすると、ファイル名が `UUID.<拡張子>` にリネームされて保存されます。
   - **元ファイルを削除する**: ONにすると、暗号化完了後にインポート元のファイルを削除します。
3. **「画像・動画を選択」** ボタンを押し、暗号化したいファイルを選択します（画像、動画、PDF、音声、テキストに対応）。

### 3. 暗号化ファイルの閲覧と管理
メイン画面の **「暗号化済みファイル一覧」** をクリックします。

- **一時プレビュー**:
  一覧の鍵アイコンのファイルをクリックすると、`tmp` フォルダに一時的に復号されたファイルが作成され、Finderでその場所が開きます。
- **フォルダを開く**:
  現在暗号化された実ファイルが保存されている `storage` フォルダをFinderで開きます。
- **暗号ファイル取込**:
  外部から既存の暗号化ファイルを直接 `storage` フォルダに追加インポートします。
- **一括書き出し（暗号化 / 復号化）**:
  保存されている全ファイルを一括で任意のフォルダにエクスポートします（暗号化したまま、または復号した状態を選択可能）。
- **全削除**:
  **「全削除」** ボタンを押すと、`storage` 内の暗号化ファイルと `tmp` 内の一時復号ファイルがすべて安全に削除されます。

## 🛠️ 技術スタックとセキュリティ仕様 (Technical Details)

### 開発環境 / 推奨要件
- **対応OS**: macOS 13.0以上
- **言語**: Swift 5.8+ (SwiftUI / AppKit 統合)
- **暗号化手法**: AES-GCM (Authenticated Encryption with Associated Data)
- **セキュリティ前提条件**: macOSの **FileVault が有効（ON）** であること

### セキュリティ詳細
1. **キー導出関数 (KDF) のカスタム実装**
   - パスワード入力時、以下の処理で `SymmetricKey` (256-bit) を生成します。
   - `SHA-256` のハッシュ値を次の入力とする処理を **3,000,000回** 反復します。
   - これにより、高速な総当たり（辞書攻撃など）を大きく遅延させ、強固な機密性を確保します。
2. **AES-GCM による認証付き暗号化**
   - ファイルの暗号化には `AES.GCM.seal(_:using:)` を使用しています。
   - 暗号化ファイルには、暗号化されたデータ本体に加え、改ざんを検知するための認証タグ（Tag）とNonceが含まれています。これにより、ファイルが第三者によって書き換えられた場合に復号を拒否する仕組みとなっています。
3. **パスワードとキーのファイル保存・キーチェーン保存を行わない設計**
   - 入力されたパスワードは、ストレッチング処理によって `SymmetricKey` を生成した直後にメモリ上から解放されます。
   - アプリの起動中は、生成された `SymmetricKey` のみが `KeyStore` (ObservableObject) 内でメモリ上に一時的に保持されます。
